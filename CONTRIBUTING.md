# Contributing

## Before starting

1. Choose an unassigned Jira work item with the team.
2. Assign it to yourself only when you are genuinely responsible for the work.
3. Move it to In Progress.
4. Create a branch such as `feature/MSD426GXUST17-5-book-session`.

## Development checks

- Keep business rules in `src/model.js` so they can be tested independently.
- Use fictional data only.
- Run `npm test` before pushing.
- Check the affected flow in a browser at desktop and mobile widths.
- Include the Jira key in the commit and pull-request title.

## Pull requests

Describe what changed, which acceptance criteria are met and how the change was tested. Request review from another team member when one is available. Do not move the Jira work item to Done until the Definition of Done is satisfied.
