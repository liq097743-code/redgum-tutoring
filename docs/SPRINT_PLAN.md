## Definition of Done

A work item can move to Done only when:

1. Its acceptance criteria are satisfied.
2. Relevant automated tests pass.
3. The feature is usable with keyboard and common mobile/desktop widths.
4. No credentials or real personal data are committed.
5. Documentation is updated.
6. A pull request has been reviewed by another member when the team has more than one member.
